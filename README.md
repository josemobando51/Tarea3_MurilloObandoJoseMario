## Descripción

Proyecto desarrollado en R, Excel y Quarto para analizar transacciones financieras mediante tres ejercicios:

1. Detección de alertas por ventana móvil.
2. Análisis de la Ley de Benford por cantón.
3. Cálculo del valor acumulado con interés.

## Estructura del proyecto

- `cod/`: scripts y funciones de R.
- `data/`: datos generados para los ejercicios.
- `config/`: parámetros personalizados.
- `excel/`: libro de Excel con cálculos y respuestas.
- `info/figuras/`: gráficos generados con ggplot2.
- `base/`: archivos originales del profesor, excluidos de Git.

## Reproducción

1. Abrir el proyecto en RStudio.
2. Clonar el repositorio base del profesor en la carpeta `base/`.
3. Ejecutar `cod/01_datos.R` para generar los archivos CSV.
4. Verificar los parámetros en `config/parametros_tarea3.csv`.
5. Renderizar `Tarea3_MurilloObandoJoseMario.qmd`.
6. Consultar los resultados en el HTML y en el libro de Excel.

## Herramientas utilizadas

R, RStudio, ggplot2, Quarto, Git, GitHub, Microsoft Excel y Power Query.
